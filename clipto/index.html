Le format choisi, vraiment.

Markdown, texte brut et code HTML sont copiés en texte uniquement. Aucune ancienne mise en forme ne se glisse dans le collage.

◎

Les limites du navigateur.

Seuls les formats que le navigateur expose sont affichés. Le RTF et le collage automatique dans une autre app restent réservés à l’application native.

⌁

Le contenu avant le décor.

Titres, listes, liens et tableaux simples sont convertis. Les images et les mises en page complexes ne sont pas reproduites.
