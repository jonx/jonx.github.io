jkSpeed v1.0.0

Control the speed of any HTML5 video - including YouTube Shorts and videos inside iframes. Keyboard-first, with real Picture-in-Picture.

  • Works on any HTML5 video - Shorts and iframe-embedded included.
  • Speed presets (1×, 1.5×) and fine-tune ±0.25× nudges.
  • Real Picture-in-Picture - pops the video into a native OS window, unlike YouTube's in-page miniplayer.
  • Customizable keyboard shortcuts (default: S slower, D faster). Fixes AZERTY / non-US keyboards where YouTube's built-in shortcuts don't fire.
  • Speed overlay, icon lights up when a video is detected.
  • Opt-in: remembers your preferred speed per site (hostnames are salted + hashed, never stored in the clear).

Demo Query Helper v1.16

Your demo script, one click away. Manage predefined queries and inject them into any web page - built for sales demos, testing, and presentations.

  • Organize queries by project with a simple text syntax: headers, presenter notes, tags, links, verbatim code.
  • WYSIWYG visual editor with a raw-text mode, search, undo, and automatic backups - your scripts survive every update.
  • Inserts into anything: plain inputs, React-style apps, rich-text chat editors, iframes, web components.
  • Page-aware: the icon lights up when the tab matches a project's URL, and that project is selected automatically.
  • Step through your script hands-free with rebindable keyboard shortcuts (F2 / F3).
  • Everything stays in your browser - no telemetry, no server, optional Chrome sync.
